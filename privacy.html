Vocabulary Bridge隐私说明使用说明

隐私说明

适用于 Vocabulary Bridge 个人 macOS 辅助程序及本介绍网站。

Google 数据访问

程序通过 Google OAuth 请求 Google Sheets 访问权限，用于读取用户配置的词库、检查重复单词及更新词条。授权范围本身不限定单个表格；程序按本地配置选择目标。现有词条主要更新主动收录次数与查询日期，不覆盖既有复习成绩。

本地文件与欧路取词

授权凭据保存在用户 Mac 的本地运行目录，不发布到此网站或开发归档。用户主动收录时，程序通过 macOS 辅助功能读取欧路取词浮窗，不需要屏幕录制权限。排查问题时，本地可能保存最近的浮窗诊断，内容可能包括释义；这类私有诊断不纳入开发归档。

欧路历史生词本 API 仅在用户提供相应令牌并主动执行导入时使用。原句和来源网址自动采集尚未实现。

传输、用途与保留

程序访问 Google Sheets 时与 Google API 通信；主动使用欧路 API 导入时与欧路服务通信。当前版本不运行独立的数据收集服务器，不出售词库或用于广告。Google 数据仅用于提供上述个人词库功能，不用于训练通用 AI 模型。词库保存在用户的 Google Sheets，受 Google 服务条款和隐私政策约束，直到用户自行删除。

撤销与删除

用户可在 Google 账号第三方连接中撤销访问，在 Google Sheets 中管理或删除数据，并自行删除 Mac 上的授权文件、私有诊断和应用。卸载程序不会自动删除 Google Sheets 词库。

本网站

网站为静态介绍页面，没有登录、分析脚本、广告或表单。网站由 GitHub Pages 托管，托管方可能按其 隐私政策处理访问日志。本应用维护者不通过页面主动收集词库。

联系与变更

疑问可通过 GitHub Issues联系维护者，请勿公开发送任何私人数据。数据处理方式改变时，此页面会更新。
