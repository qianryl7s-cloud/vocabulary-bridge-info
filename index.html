Vocabulary Bridge隐私说明使用说明

MACOS · PERSONAL LEARNING TOOL

查到一个词，
决定学会它。

Vocabulary Bridge 将欧路查词与个人 Google Sheets 英语词库连接起来，由你决定何时收录。

从查看释义到主动收录

鼠标指向英文词，按 Option 查看欧路释义。想加入词库时，保持浮窗显示，再按 ⌘ ⌥ A。

仅查词不会自动保存。程序检查重复词，维护收录次数和查询日期，保留已有复习记录。

个人使用，本地运行

这是个人使用的 macOS 辅助程序。Google 授权用于读取和更新用户配置的词库。此网站只提供介绍与说明，不提供词库登录、文件上传或数据收集功能。

了解 数据访问及隐私说明，或阅读 使用说明。

维护联系

可通过 GitHub Issues反馈问题。请勿提交词库内容、授权令牌或其他私人资料。
